# 🚀 우주 탐사 퀴즈 (Space Quiz)

우주에 관한 재미있는 한국어 객관식 퀴즈 애플리케이션입니다! 우주 탐사에 대해 배우면서 즐거운 시간을 보내세요.

## ✨ 기능

- 🌌 우주에 관한 10개의 한국어 객관식 질문
- 📊 실시간 진행도 추적 및 점수 카운터
- 🎨 라이트/다크 모드 자동 지원 (OS 설정에 따라)
- 🎭 애니메이션 피드백
  - ✅ 정답: 초록색 하이라이트
  - ❌ 오답: 빨간색 흔들림 애니메이션
- 🎉 이모지 반응이 있는 결과 화면
- 📱 반응형 디자인 (모든 디바이스 지원)

## 🏗️ 기술 스택

순수 HTML, CSS, JavaScript로 만들어진 **의존성 없는** 싱글 페이지 애플리케이션입니다.
- 프레임워크 없음
- 빌드 도구 없음
- 외부 라이브러리 없음

## 🚀 시작하기

### 로컬 실행

1. **저장소 복제:**
   ```bash
   git clone https://github.com/jhoonyeel/space-quiz.git
   cd space-quiz
   ```

2. **브라우저에서 열기:**
   - `index.html` 파일을 웹 브라우저에 드래그 앤 드롭하거나
   - 더블 클릭하여 직접 열기

3. **로컬 서버 실행 (선택사항):**
   ```bash
   # Python 3
   python -m http.server 8000
   
   # 또는 Node.js (http-server)
   npx http-server
   ```
   그 후 `http://localhost:8000` 에서 확인합니다.

## 🎮 사용 방법

1. 페이지가 로드되면 첫 번째 질문이 표시됩니다
2. 4개의 선택지 중 하나를 클릭합니다
3. 즉시 피드백을 받습니다 (정답/오답)
4. 자동으로 다음 질문으로 진행됩니다
5. 모든 10개 질문을 완료한 후 최종 점수를 확인합니다
6. "다시 시작하기" 버튼으로 퀴즈를 재시작합니다

## 📋 개발 정보

### 퀴즈 데이터 추가

`index.html` 내 JavaScript 섹션의 `quizData` 배열에 새로운 질문을 추가합니다:

```javascript
{
  question: "새로운 질문?",
  options: ["선택지 1", "선택지 2", "선택지 3", "선택지 4"],
  correct: 2  // 정답의 인덱스 (0부터 시작)
}
```

### 스타일 커스터마이징

`<style>` 섹션에서 CSS를 수정합니다:
- 색상 변경
- 레이아웃 조정
- 애니메이션 수정

항상 라이트 모드와 다크 모드 모두에서 테스트해주세요!
